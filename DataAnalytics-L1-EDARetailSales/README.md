# EDA on Retail Sales Data

## Internship
OASIS INFOBYTE — Data Analytics Internship

## Project Overview
This project explores retail sales data using Python to identify sales trends, customer demographics, and product category performance.

## Tools Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis
- Dataset inspection and missing-value checks
- Descriptive statistics
- Monthly and quarterly sales trends
- Customer age-group and gender analysis
- Revenue by product category
- Correlation heatmap
- Additional visualization and business recommendations

## Dataset
Retail Sales Dataset downloaded from Kaggle.

## Note
The dataset contains product categories rather than individual product names. Therefore, product-category analysis is used where individual product-level analysis is not possible.
