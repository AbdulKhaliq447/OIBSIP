# Google Play Store Analysis

## Internship
OASIS INFOBYTE – Data Analytics Internship

## Project Title
Task 4: Unveiling the Android App Market (Google Play Store Analysis)

## Project Objective
The objective of this project is to analyze Google Play Store applications and user reviews.
The project focuses on data cleaning, app categories, ratings, installations, pricing trends and sentiment analysis.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- TextBlob
- Jupyter Notebook

## Project Activities
- Loaded Google Play Store apps and user reviews datasets.
- Checked missing values and duplicate records.
- Cleaned app ratings, installs, prices and sizes.
- Analyzed app categories and ratings.
- Compared free and paid applications.
- Studied app size and installation relationships.
- Performed sentiment analysis on user reviews.
- Created charts and interactive visualizations.

## Project Files
- Jupyter Notebook containing the analysis.
- Original apps and user reviews datasets.
- Cleaned datasets.
- Sentiment analysis results.

## Conclusion
This project provides insights into Google Play Store applications, app competition, user ratings, pricing and customer sentiment. These findings can help app developers make informed decisions.
