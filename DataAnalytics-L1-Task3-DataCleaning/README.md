# Data Cleaning Using Python

## Internship
OASIS INFOBYTE – Data Analytics Internship

## Project Overview
This project focuses on cleaning and preparing the Titanic dataset using Python. The objective is to identify and fix data quality issues and prepare a clean dataset for further analysis.

## Tools and Libraries
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Data Cleaning Tasks
1. Loaded and inspected the Titanic dataset.
2. Checked missing values in each column.
3. Identified and removed duplicate rows.
4. Handled missing values using median and mode.
5. Standardized categorical data.
6. Corrected data types.
7. Detected outliers using the IQR method.
8. Compared data before and after cleaning.
9. Saved the cleaned dataset as a new CSV file.

## Files Included
- `OIBSIP_Data_Cleaning.ipynb` – Jupyter Notebook containing the complete cleaning process.
- `titanic.csv` – Original dataset.
- `cleaned_titanic.csv` – Cleaned dataset.

## Conclusion
The Titanic dataset was cleaned by handling missing values, removing duplicate records, standardizing categorical values, correcting data types and detecting outliers. The cleaned dataset is now ready for further analysis.
